# SEASON 2 PLAN — a game that goes up and down (agreed with Shad, 2026-11-10)

Shad: "the game right now feels very flat and boring ... we want to bring more life to it, more adventure, more fun,
more variety." Kinan should go up and down, not only left to right: climb ladders, drop down pipes and chutes, find
secret rooms, wall-jump up shafts, grab ledges, climb, swim, with the camera following him high up and deep down.

Shad answered 32 multiple-choice questions; this file is the record. Build in **small steps, one per session**, each
one tested, played by Shad, then pushed live ("small updates often"). Shad decides if a step feels right.

## The decisions
| Topic | Decision |
|---|---|
| 2D or 2.5D | **Stay 2D**, but greatly improve graphics, feel and how levels work |
| When | The new **moves** (wall jump, ledge grab, climbing, swimming) start **after World 11**. Ladders, pipes/chutes/doors and secret rooms need no new skill, so they go into **Worlds 1-11 too** |
| Goal | All equally: movement that feels fun, exploring and secrets, variety of places |
| Level shape | Mostly left to right but **tall**: big climbs and deep dives, some levels mainly up or down |
| New moves | Wall jump, ledge grab, climbing (vines, ladders, rock, fences), swimming |
| Wall jump | **Very forgiving**: slow wall slide, tap JUMP to bounce |
| Learning the moves | **Sabumnim** teaches them (taekwondo story) |
| Story reason | **Both**: Glitchy's escape bent the worlds taller and deeper, and Sabumnim trains Kinan for them |
| Touch controls | **No new buttons**: JUMP near a wall wall-jumps; ledges and climbing happen on touch |
| Followers (pets, Robin, Shad) | **Poof back beside Kinan** when they fall behind; they give **small helps** (a boost up, stand on a button, show a hidden handhold) |
| Camera | Smooth follow in every direction, looking ahead; zooms out a little for big climbs and dives (Shad skipped this one: our pick) |
| Long falls | **Land lower, no harm**; only bottomless pits cost a heart |
| Underwater | **No air limit** |
| Level length | About 5-8 minutes, with checkpoints (our pick) |
| Places | Mountains and cliffs, underwater / ocean, tall buildings, caves and mines, and more themes |
| Secrets | The best ones (golden candles, secret exits) **way up high and deep down**; the main path stays easy |
| Puzzles | Switches and doors, water levels (raise / lower), friend teamwork, physics (crates, seesaws, ropes, boulders) |
| Bosses | **Tall arenas** to wall-jump and climb in, mixed with today's flat fights |
| World 12 (3D sneak peek) | **Keep it as a 3D bonus world** (built already); the new 2D era starts in the world after it (our pick) |
| Worlds 1-11 | Keep their levels; add hidden paths / secret rooms (ladders, pipes, chutes, doors), the juice upgrade, and **one optional challenge stop per world** that uses the new moves once learned |
| New moves in old levels | **Only in new levels** (old levels keep their rules so they play as designed) |
| Feel today | Shad wants all of it better: jumping / running, graphics, juice (dust, squash, sparkles, shake, sounds), levels too flat |
| Juice upgrade | **Everywhere**, Worlds 1-11 included |
| Pipes / chutes / doors lead to | A mix: underground areas, rooftops, secret rooms, shortcuts. Themed per world, not copied from another game (laundry chute at home, vents at school, oil pipes at Dad's rig, manholes in Toronto) |
| Secret rooms hold | Treasure, mini challenges, story surprises (family memories, funny scenes, Easter eggs), shortcuts |
| More life | Things to ride (elevators, zip lines, minecarts, rafts, skateboard), living worlds (people and animals, weather, day and night), interactive stuff (trampolines, breakable walls, buttons, hiding spots, helpers), mini-games inside levels |
| Prototype | A **playground** test level first |
| Playtest | Shad plays each step |
| Pace | Small steps, one per session |

## Build order
**Phase A — the whole game feels alive (Worlds 1-11 too)**
1. Engine groundwork: taller levels, a camera that follows up and down, doors / pipes / chutes into other areas, and a
   playground test level (developer-only).
2. Ladders, pipes, chutes and secret rooms (treasure, mini challenge, story surprise, shortcut).
3. Better running and jumping, and the juice effects, in every world.
4. Worlds 1-11, one world per session: hidden paths and secret rooms that fit each place.
5. Things to ride and play with; living backgrounds.

**Phase B — the new era after World 11**
6. Wall jump, ledge grab, climbing, swimming; Sabumnim's training scene.
7. Puzzles: switches and doors, water levels, friend teamwork, crates and ropes.
8. New worlds (mountains, ocean, towers, caves), tall boss arenas, mini-games; a challenge stop on each old world's map.
